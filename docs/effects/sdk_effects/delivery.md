# Delivery checkpoints

Root coordinates shared registries and integrated checks. Independent workers own
new effect directories or the driver subsystem with explicit file ownership.
Use bounded serial checks on the shared workstation; no parallel browser/build
campaigns. Keep captures and reports under ignored `artifacts/`.

## 1. Shared timeline in Studio

Reuse the existing dock below both workspaces. Retain one transport and panel
through workspace switches. Verify Motion conversion, playback/scrub, pin/peek,
mobile access, object/dock clearance, capture guides and byte-equivalent export.

## 2. SDK capability and placement

Extend current definitions with common spatial/area controls and semantic roles.
Verify strict imports, legacy output/defaults, actual GPU area coverage, nested
owner transforms, undo, preview cancellation and existing nonmodal focus behavior.
Migrate all built-ins without requiring custom React for ordinary controls.

## 3. Durable one-click time drivers

Replace phase-only preview authoring with real Motion instances. Exercise numbers,
colors and discrete values through creation, edit, enable, trim, undo and export.
Test loop boundaries, nonsequential seeking and sparse channel serialization.

## 4. Composition-effect owners

Add durable effect-owner targets to the shared composition/scene animation path.
Verify property lookup, compilation, apply, validation, timeline projection,
history, deletion pruning, duplication, clipboard remapping and saved reload.
Layer and composition stacks must expose identical basic authoring capabilities.

## 5. Interaction and replay

Add semantic pointer/drag/click inputs, analytic response and bounded input takes.
Verify mouse, touch and keyboard tests; explicit ownership against camera/gizmos;
one completed-recording undo; cancellation and listener/clock cleanup. Compare
live, seeked and decoded exported frames at identical recorded timestamps.

## 6. Missing effects

Implement Risograph, Oil Painter, Chromatic Aberration, LEGO Blocks and Wind with
their own metadata/resources/TSL modules. Add true temporal sampling for Trail and
native depth input for DOF through reusable renderer capabilities. Update search
and bake distinctive static thumbnails only after visual validation.

## 7. Performance and completion

Measure actual input-to-acknowledged-frame latency and parent React counters.
Verify bounded sources, taps, caches and pending work; zero production pixel reads;
no idle animation work after inputs/transport stop. Run the relevant 50-image /
100-effect workload once shared compositor/temporal/depth work is complete.
Do not use shell LCP or a stable React counter as proof of gesture responsiveness.

Each delivered milestone receives an English changelog entry and a deliberate
commit after its focused checks and the rules check pass. Full release gates stay
in CI/requested release preparation. Record actual results, failures and remaining
limitations; do not check off a capability based only on its planned interface.
