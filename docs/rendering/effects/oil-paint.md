# Oil Painter

This effect performs a bounded, directional approximation of the classical four-region Kuwahara filter. Its algorithm reference is the regional mean/variance construction in [Papari, Petkov and Campisi, Artistic Edge and Corner Enhancing Smoothing (IEEE TIP, 2007)](https://www.cs.rug.nl/~imaging/artisticsmoothing/TIP_artistic.pdf). That paper's generalized method is not implemented here: this is the simpler four-overlapping-region variant, with an oriented brush footprint and explicit source-detail restoration. The intended appearance is broad, coherent patches following image edges, rather than simulated wet paint or a library of stamped brush images.

Each pixel samples a rotated 5×5 stencil. Four overlapping 3×3 regions share these samples, giving exactly 25 source reads including the original pixel. Each region accumulates premultiplied RGB, alpha-weighted luminance and alpha-weighted squared luminance. The region with the smallest luminance variance supplies its alpha-normalized mean color. Empty regions cannot win; an entirely transparent neighborhood falls back to original RGB. Source alpha is returned unchanged, so there is no dilation or coverage loss and hidden transparent colors do not enter the averages.

`brushScale` sets the short semi-axis in document pixels (0.5–32), and `elongation` scales the long axis (1–4). `angle` rotates the sampling frame. `directionality` adds a bounded fraction of the polar angle around normalized `centerX`/`centerY`, allowing brush regions to follow a radial direction field. Set directionality to zero for a uniform brush direction. The center positions this field without moving source content. `edgePreservation` restores source color where the selected region differs strongly from the center pixel; `detail` blends back original detail everywhere. Amount then blends the complete treatment with the source. At detail one or amount zero the original image is restored.

The sample count is fixed regardless of brush radius, image dimensions or animation settings. Large brush values intentionally use sparse samples and can show angular patches; this is neither a dense large-window Kuwahara filter nor an anisotropic structure-tensor implementation. It models no pigment, canvas relief, lighting, fluid history or impasto. There is no implicit clock, seed, scratch texture, CPU image processing or GPU readback. All controls use ordinary definition-owned fields and the generic property/Motion pipeline.

## Verification status

Focused metadata/transaction and bounded graph regressions are supplied for brush bounds, wrong types, rejected nonfinite values, undo/redo, source alpha, fixed sample budget and stable uniforms. Execution and real WebGPU/WebGL2 photographs, transparency, masks, exports and cross-density visual inspection are deferred because this implementation session explicitly prohibits tests, builds and browser checks. No GPU correctness or performance result is claimed.
