# Risograph

This original GPU print interpretation separates a photograph into two or three editable inks, screens each ink independently and multiplies their translucent reflectances over tinted paper. The visual and process references are [RISO's ink/drum technology](https://www.riso.co.jp/english/tech_portal/core/ink.html) and the [School of the Art Institute of Chicago's risography guide](https://sites.saic.edu/servicebureau/home/services/risography-printing/): stencil drums, limited spot colors, translucent overlap and imperfect registration. No artwork or shader implementation is copied.

Duotone separates luminance darkness and red-versus-blue chroma into two inks. Tritone uses complementary RGB deficits as three separation masks. Contrast and ink density shape those masks. Three dot screens, rotated by 60 degrees relative to one another, vary dot radius with separation coverage. An authored half-pixel edge and a continuous solid-ink transition avoid a hard dot cutoff. Grain changes ink deposition independently in each pass. Paper has a separate elongated fiber hash. These are artistic separations, rather than a color-managed spot-ink conversion or spectral ink model.

The portable unsigned integer seed produces independent two-axis offsets for each ink and independent spatial grain. `misregistration` bounds each offset axis to ±24 document pixels. `angle` rotates print screens and the registration directions. Normalized `centerX`/`centerY` anchor print screens, grain and paper in the authored layer frame; they are useful for positioning or animating a screen across an image. They do not move the layer. Dot size is 1–32 document pixels. The graph uses four source reads, independent of radius or output dimensions, with no textures allocated by the effect, CPU composition or pixel readbacks.

Source alpha is returned directly. Shifted color samples are weighted by their alpha before separation, so hidden transparent RGB cannot become an ink fringe. Paper is confined to the existing silhouette. Amount zero restores original RGB; masks and optional compositing remain in the shared stack. There is no implicit time or frame-varying random seed. All numeric settings use the generic property and Motion machinery.

## Verification status

Focused metadata/transaction and bounded graph regressions are supplied. They check invalid imported values, undo/redo, conditional third-ink visibility, preserved alpha, integer seed dependencies, authored coordinates and stable uniforms. Execution, native WebGPU/WebGL2 photographs, decoded exports, nested masks and cross-density visual inspection are deferred because this implementation session explicitly prohibits tests, builds and browser checks. No GPU correctness or performance result is claimed.
