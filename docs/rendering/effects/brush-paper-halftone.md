# Circular screens, Torn Edges and Liquify

## References and interpretation

Adobe documents [Color Halftone](https://helpx.adobe.com/photoshop/desktop/effects-filters/artistic-stylize-filters/apply-distortion-and-stylize-filters.html)
as printed channel screens with a radius and independently angled channels.
[Liquify](https://helpx.adobe.com/photoshop/desktop/effects-filters/artistic-stylize-filters/use-liquify-to-distort-an-image.html)
uses forward warp, pucker, bloat and twirl brushes with size and pressure controls;
[reconstruction](https://helpx.adobe.com/photoshop/desktop/effects-filters/artistic-stylize-filters/reconstruct-distortions.html)
restores prior distortion locally. Adobe's [filter reference](https://helpx.adobe.com/photoshop/desktop/effects-filters/blur-sharpen-filters/filter-effects-reference.html)
classifies Torn Edges as a sketch treatment producing ragged paper pieces and recoloring them.
These describe the target behavior, not published shader algorithms. Melt uses its
own deterministic TSL implementations; it does not claim pixel-identical Photoshop output.

## Halftone

Omitted settings retain the original classic print graph. Circle grid uses
luminance-controlled nonoverlapping round dots; the source-color switch retains
sampled layer colors instead of custom ink. Round color mosaic uses fixed-radius
circles with each cell's original color. Color channel screens use separate
cyan, magenta and yellow dot coverage reconstructed as RGB, with independent
angles (108°, 162°, 90°), rather than a color-managed four-plate CMYK separation.
Spacing, rotation, radius, feather, gamma and offsets use authored document units.
Custom ink/paper and paper opacity are available where applicable. Pattern-specific
controls are hidden for the legacy graph. Color sampling is performed on GPU textures.

## Torn Edges

Graphic mode smooths source luminance, adjusts balance/contrast, perturbs the
threshold with seeded multiscale paper noise and recolors with ink/paper colors.
Paper mode cuts the authored content rectangle's independently enabled sides,
using tear depth, roughness, fiber scale/detail and feather. An inner torn-edge
color transitions to paper or the original image. Alpha mixing is premultiplied;
zero amount retains the source. The graphic interpretation follows the sketch
reference; paper silhouette is an additional frame treatment.

## Liquify

Selecting a Liquify attachment activates a round brush over its 2D layer.
Push deforms in the drag direction. Pinch, inflate and both twirls change a local
region; reconstruct attenuates earlier distortions under the brush. Radius,
strength and hardness affect newly painted samples; amount scales the accumulated
deformation. Pen pressure can modulate strength. Reset removes the deformation.
Brush coordinates are normalized to layer dimensions and include authored brush
settings, so resizing retains their relative placement. Nested 2D transforms are
inverted before capture. Perspective/volumetric 3D authoring is intentionally
unavailable: flatten to a 2D composition to paint there.

The GPU evaluates the reverse authored sequence as an inverse UV warp. Reconstruct
samples accumulate a protection weight for earlier samples. Pixels sampled outside
the available texture are transparent, and output remains clipped to the layer's
transport surface. This is a sparse brush field, not Adobe's mesh implementation.
There are at most 256 brush samples per effect; samples are spatially spaced to
avoid recording every input packet. At capacity the UI reports it explicitly;
undo, reset or another Liquify operator permits further work. No samples are
silently pruned, and no document keys are generated by playback.

During a gesture, previews and cursor position use imperative ports. Release commits
once; Escape, pointer cancellation, blur, hidden tabs or stale ownership cancel.
Escape outside a gesture leaves painting without changing the layer selection.
Each completed stroke and reset participates in normal undo/redo, portable archives
and embedded replay. Only bounded coordinates cross to GPU uniforms; production
pixels and GPU buffers are never read into JavaScript.

## Verification

Focused core tests verify strict settings/sample validation, a legacy Halftone
roundtrip, exact stroke undo/redo and technique-specific controls. Native WebGPU
and WebGL2 witnesses inspect decoded output pixels for all print modes, both Torn
Edges techniques, push/pinch/inflate/twirl/reconstruct, deterministic seeds and
zero-amount identity. Fifty independent image textures through the combined stack
retain three materials and one 96 × 64 scratch target (24,576 bytes) after warmup.
Application GPU/WebGL/Canvas2D/VideoFrame readback probes report zero.

The editor gesture test checks a visible GPU preview without root React commits,
Escape cancellation, one stroke per undo entry, redo, reset and exact pixel
restoration. Generated native evidence is under ignored `artifacts/brush-paper/`.
These are correctness/resource checks; they do not establish a universal latency
or claim pixel equivalence with Adobe's proprietary filters.
