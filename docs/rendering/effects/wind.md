# Wind

Wind stretches existing source colors into irregular directional streaks. Its primary visual reference is the windblown stylization described in [Adobe's filter reference](https://helpx.adobe.com/in_hi/photoshop/using/filter-effects-reference.html). This is an original bounded gather filter, not an implementation of Adobe's Wind, Blast or Stagger algorithms and not a ripple alias.

Direction rotates a document-space flow axis. The normalized center positions both the crosswind bands and the along-wind gust field. Each authored-pixel band has a stable exact-integer-seeded length variation. A sinusoidal gust further modulates that length using explicit phase, speed and document time. Spatial and temporal phases are each reduced modulo one cycle before combination and multiplication by 2π. Re-evaluating the same source, seed, phase and time reproduces the same field; speed zero freezes its gusts. No simulation history or generated document keyframes are involved.

Twelve finite source taps gather upwind, weighted toward the current pixel. Premultiplied color/alpha accumulation ignores hidden RGB, followed by unpremultiplication and an adjustable original-detail mix. Output alpha remains the original per-pixel alpha, so streaks remain within the existing silhouette. Clamped sampling bounds each lookup. Zero length and full original detail are identity treatments; amount provides the common source mix. Including the original lookup, this graph has at most thirteen source samples, no extra targets and no GPU pixel readbacks.

This is a photographic approximation to directional smearing. It has no physical fluid model, motion-vector estimation, temporal feedback or long-range trail history. Its fixed tap count may show discrete streak structure at very long lengths; band variation and gust controls intentionally vary the stretch rather than adding arbitrary scene geometry. Periodic calculations still use the GPU's float32 time precision.

Visual acceptance requires elongated photographic detail aligned with the chosen direction, visibly uneven bands, a useful source-detail mix and changed gusts at distinct explicit times. Inspect 0°/90°/180° directions, translated centers, speed zero, length zero, full original detail, maximum length, high unsigned seeds and graded-alpha sources.
