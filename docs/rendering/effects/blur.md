# Blur library

One portable `blur` effect owns seven bounded spatial kernels. Old documents with no settings resolve to Gaussian, retaining its original two 17-tap passes, standard deviation `amount × scale`, expanding transparent margins and premultiplied RGBA interpolation. Three.js TSL builds every graph for the existing WebGPURenderer owner and its WebGL fallback; no other renderer or CPU image filter is used.

| Technique   | Kernel and controls                                                                                                                         | Deliberate limit                                                                     |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Gaussian    | Separable 17 × 17 Gaussian, finite ±3.2σ support                                                                                            | Bounded sampled approximation                                                        |
| Box         | Two uniform 33-tap axes, half-width √3σ                                                                                                     | Discrete approximation to a rectangular convolution                                  |
| Directional | 33 uniform line samples with editable document-space angle                                                                                  | Spatial streak, without temporal frames or velocity data                             |
| Spin        | 33 samples on a rotation arc about the authored center; editable sweep angle                                                                | Scale caps displacement to retain bounded transport                                  |
| Zoom        | 33 radial line samples about that center; editable fractional reach                                                                         | Symmetric spatial zoom streak, capped by scale                                       |
| Lens        | 64 deterministic equal-area disk samples mapped into a polygonal aperture, weighted by the area Jacobian; editable blade count and rotation | Flat image aperture convolution; no depth or focal-plane simulation                  |
| Bilateral   | Joint 7 × 7 spatial Gaussian and premultiplied linear RGBA range weighting; editable range sigma                                            | Finite local edge-preserving filter; transparent edges participate in range distance |

Box/directional supports are ±√3σ; lens radius is at most 2σ, bilateral support ±3σ, and spin/zoom displacement is capped by √3σ. Every technique therefore retains the original ±3.2-scale footprint reservation, stable through amount animation and technique changes. Here σ is `amount × scale`; spin and zoom also scale their actual arc/reach by amount. Spatial fields use the original authored content rectangle inside expanded transport margins.

Protection is opt-in. The existing radial effect gizmo edits the original-content center, sharp radius and outer feather ring. Final treatment uses the untouched pre-effect backdrop, including across both separable passes and preceding effects. Protected pixels retain that input exactly; the annular transition interpolates premultiplied RGBA, with a hard edge when feather is zero. Preview remains imperative and commits one validated command per completed gesture.

Algorithm references: [Three.js GaussianBlurNode](https://threejs.org/docs/pages/GaussianBlurNode.html) documents premultiplied filtering; [OpenCV's smoothing reference](https://docs.opencv.org/4.x/d4/d13/tutorial_py_filtering.html) describes normalized box convolution; [Tomasi and Manduchi, Bilateral Filtering for Gray and Color Images](https://users.soe.ucsc.edu/~manduchi/Papers/ICCV98.pdf) defines joint spatial/range weighting. [PBRT's thin-lens model](https://www.pbr-book.org/4ed/Cameras_and_Film/Projective_Camera_Models) explains the scene-depth/focus information a true depth-of-field model requires; this 2D aperture convolution does not claim those properties.

Focused regressions are in `packages/core/test/effects/blur`, `packages/render/test/effects/blur`, shared radial gizmo tests, and `test/browser/blur-library.spec.ts`. Native output inspection is isolated from production readback probes; generated evidence belongs under ignored `artifacts/blur-library/`.

Native center/ring gestures retained the five editor-root React counters, committed once and supported undo, redo and Escape cancellation. The shared technique selector exposed seven choices without changing body styles.

After the second canonical frame allocated the ordinary 512 × 256 presentation back buffer, target count remained 156, source uploads remained one and charged cache bytes remained 7,775,152 of the 402,653,184-byte budget through strength changes and undo. This is a resource-reuse witness, not the full 2400 × 1500 benchmark or a latency comparison. Instrumented production WebGPU, WebGL, Canvas2D and VideoFrame pixel-read counters stayed at zero.
