# Effect previews

The six WebP previews are actual Melt TSL effect exports of the existing local
boathouse fixture (`/benchmark/06-boathouse-1.jpg`), resized with the browser's
native image preparation/encoding APIs. They are not CSS simulations.

Photo: Luca Bravo, Unsplash. Source and license are recorded in
`../../benchmark/ATTRIBUTION.md` and `../../benchmark/manifest.json`.

Effects: ASCII, two-color Dither, Halftone, Cyanotype, CRT, Posterize. Reproduce by
opening the corresponding image converter, selecting the boathouse fixture,
leaving effect defaults and exporting WebP. Card files use a native 640 × 480
thumbnail at WebP quality 0.84.
